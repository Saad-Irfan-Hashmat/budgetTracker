# Budget Tracker
 
A Windows Forms Budget Tracker developed in C#.
 
Features:
- User Registration
- User Login
- Add Expenses
- View Expenses
- Update Expenses
- Delete Expenses
- Calculate Total Expenses
 
OOP Concepts:
- Encapsulation (Expense class)
- Abstraction (Transaction class)
- Inheritance (ExpenseTransaction class)
- Polymorphism (Override GetAmount())
 
Database:
- SQL Server LocalDB
- expense.mdf
 
How to Run:
1. Open Budgettracker.sln
2. Restore NuGet packages
3. Build Solution
4. Run project
